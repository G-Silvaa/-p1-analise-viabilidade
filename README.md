# P1 — Análise de viabilidade de IA no atendimento a estudantes

Projeto P1 do percurso **Sistemas Agentes (SOFTEX)**: análise técnica sobre **onde, como e sob quais condições** usar inteligência artificial no atendimento de uma instituição de ensino digital — e onde **não** usar.

> 🚧 Em andamento — nível Básico concluído.

## Estrutura

| Pasta / arquivo | Conteúdo |
|---|---|
| `analise/` | Fluxo atual, decomposição das atividades e análise das funcionalidades |
| `prompts/` | Prompts protótipos (versões) |
| `testes/casos.json` | Casos de teste fictícios com resultado esperado |
| `testes/rodar_testes.py` | Script que executa um prompt sobre os casos e gera relatório |
| `resultados/` | Respostas brutas do modelo + análise de cada rodada |
